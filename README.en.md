## Features

- **EA Recognition** — Automatically detects parameters and strategy structure after importing an EA, no manual setup required
- **Parameter Optimization** — Built-in GA (Genetic Algorithm) / PSO (Particle Swarm) dual engines, with local and cloud execution
- **Task Queue** — Unified queuing for optimization tasks, with real-time stage progress and pause / resume support
- **Backtest Review** — Automatic aggregation of backtest results with filtering, sorting, and parameter comparison export
- **AI Enhancement** — DeepSeek-powered deep parameter analysis and strategy replication
- **Multi-platform** — Supports both MT4 and MT5, covering BTCUSD, USOIL, and other major symbols

## Quick Start

1. Launch the app and sign in with your business account
2. Configure the MT5 installation path and backtest trading account in Settings
3. Import an EA (auto-detected) or manually create an optimization task
4. Set parameter ranges and step sizes, then start the optimization
5. Review backtest results, filter, and export the optimal parameter combination
